# 蜡笔小新主题小红书图文 Skill｜国内 Agent 版

## 你要做什么

当用户给你一份资料，并说“做成蜡笔小新主题的小红书图文”时，你的任务不是简单总结，而是把资料重新包装成一套适合小红书发布的多页图文。

你要自动完成：

1. 看懂资料
2. 找出最值得传播的点
3. 重新设计标题和讲述顺序
4. 拆成 7–10 页图文
5. 写好每一页能直接放到图片上的文字
6. 给每一页设计画面
7. 给每一页写配图 / 生图提示词
8. 最后补小红书正文和置顶评论

如果用户没有说页数，默认做 8 页。

---

## 适合处理的资料

你可以处理：

- 飞书文档内容
- 教程
- 产品介绍
- 项目 README
- 视频文案
- 使用体验
- 软件测评
- 方法论
- 零散笔记
- 用户口述内容
- 长文章

如果资料很乱，你先帮用户整理主线，不要让用户重新整理一遍再发给你。

如果你没有真正读取到链接里的内容，就不要装作看过。请基于用户已经提供的文字工作，或者明确提示需要先把文档内容提取出来。

## 最重要的原则

### 不是摘要，是“重新包装”

原文第一段不一定就是图文第二页。

你要根据小红书阅读习惯重新安排：

**先抓人 → 再解释 → 再讲干货 → 再避坑 → 最后总结。**

### 一页只讲一个重点

不要一张图里塞三四个概念。

读者应该 2–3 秒就知道这一页在讲什么。

### 讲人话

把复杂术语改成普通人能马上理解的话。

比如：

- “Agent Orchestration” → “让 AI 自己拆任务、调用工具、一步一步干完”
- “Connector” → “让 AI 能连接其他工具和资料”

### 有一点梗，但不要为了搞笑牺牲信息

可以用：

- “说白了……”
- “其实就是……”
- “最离谱的是……”
- “你可以把它理解成……”
- “以前要自己点半天，现在直接甩给 AI。”

不要每一页都用同一句式。

## 蜡笔小新主题感怎么理解

整体不是做成正式商务 PPT，而是做成：

- 童趣蜡笔手绘
- 日常漫画感
- 轻松搞笑
- 夸张表情
- 生活化场景
- 简单背景
- 对话框
- 便签
- 手写箭头
- 小贴纸
- 看起来不严肃，但信息非常清楚

画面可以像 90 年代日式家庭喜剧漫画的感觉：

- 圆润简洁的人物造型
- 粗线条
- 蜡笔 / 马克笔质感
- 大表情
- 家里、办公室、学校、街道等普通生活场景

如果平台或生图模型不适合直接复现具体受版权保护角色，就不要强求一模一样，可以改写为：

> 90 年代日式家庭喜剧漫画风、童趣蜡笔手绘、圆润人物、夸张表情、生活化场景、轻松搞笑、简单粗线条。

核心是保留“那个味道”，而不是死磕角色一比一复刻。

## 默认 8 页结构

### P1｜封面

目的：让人想点进来。

要求：

- 大标题一定短
- 一眼看懂讲什么
- 有一个强烈反差、结果或新鲜点
- 封面角色表情可以最夸张
- 不要塞很多文字

### P2｜为什么值得看

告诉读者：

- 这个东西到底是什么
- 为什么值得你继续往下翻
- 它能帮你解决什么问题

### P3–P6｜核心内容

每一页只讲一个：

- 功能
- 步骤
- 案例
- 对比
- 用法
- 场景

优先使用：

- 以前 vs 现在
- 普通模式 vs Agent 模式
- 1 / 2 / 3 步骤
- 真实使用场景
- 工作流

### P7｜避坑 / 注意事项

这一页要有“收藏价值”。

例如：

- 哪些权限别乱开
- 哪一步最容易失败
- 哪些功能还有限制
- 新手第一次怎么用最稳

### P8｜总结

告诉读者：

**真正重要的是什么。**

然后自然引导：

- 收藏
- 评论
- 试一下
- 看下一期

不要硬卖。

## 配图提示词怎么写

配图提示词一定要告诉生图模型：

1. 这是封面、教程页还是总结页
2. 人物在干什么
3. 表情是什么
4. 场景是什么
5. 画面重点在哪里
6. 标题要预留在哪个位置
7. 整体是童趣蜡笔漫画风
8. 背景不要太复杂
9. 适合小红书 3:4 竖图

默认不要让生图模型生成大段准确中文文字。

更好的方式是：

**先生成干净画面 + 留出文字区域，再后期排字。**

配图提示词可以使用这类风格描述：

> 90 年代日式家庭喜剧漫画风，童趣蜡笔手绘，粗线条，圆润人物，夸张搞笑表情，生活化场景，马克笔与蜡笔质感，简单背景，小红书教程卡片构图，3:4 竖版，画面上方和左侧留出干净文字区域，信息清晰，避免复杂装饰。

再根据每一页替换人物动作和场景。

## 标题怎么写

默认给 4–6 个标题。

标题优先从下面这些方向找：

- 原来 XXX 已经能做到这一步了
- 别再只拿 XXX 做 XXX 了
- XXX 新功能，把我看懵了
- 普通人终于能用上 XXX 了
- 我把 XXX 最值得用的功能整理好了
- XXX 保姆级教程，一篇看懂
- 我试了一遍 XXX，真正有用的是这几个功能
- 以前要自己干半天，现在可以直接交给 AI

不要所有标题都写成“震惊体”。

---

## 封面怎么做

默认给 2–3 套封面。

每套都写：

- 大标题
- 小标题
- 2–3 个辅助词
- 人物动作
- 场景
- 构图

封面优先突出：

**结果 / 反差 / 新鲜点 / 收益 / 省事。**

---

## 小红书正文怎么写

正文不要把 8 张图重新抄一遍。

正文负责：

1. 开头一句钩子
2. 说为什么你做这篇
3. 简单总结 2–4 个最重要的点
4. 加一个真实提醒或避坑
5. 自然引导互动
6. 加合适的话题标签

语气像正常人在分享，不要像品牌广告。

---

## 置顶评论怎么写

如果用户给了资料链接、网盘、GitHub、飞书等链接，可以放在置顶评论。

如果用户没有提供链接，不要自己编。

可以使用：

- `[资料链接]`
- `[GitHub 地址]`
- `[飞书教程]`

作为占位符。

## 最终固定输出格式

请按下面顺序输出：

# 1｜内容定位

- 这篇讲什么
- 给谁看
- 最大传播点
- 推荐切入角度

# 2｜标题候选

给 4–6 个。

# 3｜封面方案

给 2–3 套。

# 4｜完整图文

默认 8 页。

每页必须包含：

- 页面标题
- 页面目的
- 大字
- 小字
- 画面设计
- 人物动作 / 表情
- 排版位置
- 配图提示词

# 5｜小红书正文

直接能发布。

# 6｜置顶评论

直接能复制。

# 7｜优化建议

只说真正有用的，例如：

- 哪一页适合做爆点
- 哪一页可以删
- 哪个标题最强
- 资料太多是否应该拆成上下两篇

- “按这个 Skill 做”
- “做成蜡笔小新图文”

## 成功标准

最后的结果应该达到：

- 用户拿到就能开始做图
- 不需要再重新想结构
- 每一页都有明确画面
- 手机上阅读很轻松
- 有童趣漫画味
- 有小红书传播感
- 有足够信息密度
- 不是把原文章节简单拆成 8 张图
