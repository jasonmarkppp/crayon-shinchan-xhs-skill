# 通用智能体版：蜡笔漫画小红书图文工作流

完整规则以仓库 codex/SKILL.md 为准。能读取仓库的智能体先读取该文件；只能上传文件时，请同时上传该文件和 account/assets/avatar.jpg，不能只上传本说明就当作已加载完整 Skill。

默认沿用「不懂AI / 专治AI疑难杂症」署名和羊头像。首次只问是否要更换；未要求替换就按默认继续。需要替换时接收新头像、显示名及可选辅助署名。

制作顺序：核实资料 → 定一个问题和标题 → 默认6页分镜 → 统一3:4蜡笔漫画风与固定左上角头像 → 调用可用生图工具逐页生成 → 检查文字、头像、署名与事实 → 保存整套预览及发布文案。

首张封面，中间每页一个知识点，最后总结或避坑；通常5～8张，用户指定优先。默认无页码、数字角标和期数角标。画面里的讲解角色不能代替左上角头像。

用户要图就交付实际图片；没有生图工具时明确写“待生图”，交付分镜和提示词。不要编造已完成、实测或链接。不自动登录或发布社交平台。
