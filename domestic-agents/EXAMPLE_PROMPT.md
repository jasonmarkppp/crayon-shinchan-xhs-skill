# 国内 Agent 调用示例

把 `SKILL.md` 上传给 WorkBuddy、豆包或其他 Agent 后，再发送：

```text
请严格按照我上传的《蜡笔小新主题小红书图文 Skill》执行。

下面是我的原始资料：
[粘贴资料 / 上传文件 / 提供已经提取好的文档内容]

目标：
- 做成 8 页小红书图文
- 3:4 竖版
- 不是摘要，要重新找传播角度
- 整体是蜡笔小新主题感：童趣蜡笔漫画、轻松吐槽、夸张表情、生活化场景
- 每页只讲一个重点
- 每页都要给“上图文字 + 画面设计 + 人物动作 + 生图提示词”
- 最后给小红书正文和置顶评论

直接给完整版本，不要先问我一堆问题。
```

## 适合豆包 / WorkBuddy 的更短触发词

```text
按 Skill，把这份资料做成 8 页蜡笔小新主题小红书套图。重点不是总结，而是重新包装传播角度。直接输出完整成品。
```
