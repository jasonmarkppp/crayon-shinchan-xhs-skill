# 蜡笔漫画小红书图文工作流

把资料或主题做成一整期漫画知识套图：核实资料 → 定题 → 分镜 → 固定头像和署名 → 逐页生图 → 检查 → 整套预览与发布文案。

默认 6 张、3:4 竖版、奶油蜡笔质感；每页一个知识点。左上角保留作者的羊头像及「不懂AI / 专治AI疑难杂症」署名，也可以换成你自己的。

## 开始使用

1. 下载或克隆整个仓库，保留 `codex/` 和 `account/assets/` 的相对结构。
2. 让支持读取文件和生图的智能体读取 [codex/SKILL.md](codex/SKILL.md)。不同产品的 Skill 安装方式不同，直接读取文件也能使用；不要只复制 SKILL.md 后丢掉头像资源。
3. 提供主题或资料，发送下面的指令。

```text
读取 codex/SKILL.md，把我的资料做成 6 张蜡笔漫画小红书图文。
沿用默认的羊头像和「不懂AI / 专治AI疑难杂症」署名。
先核实内容、写分镜，再生成实际图片，保存整套预览和发布正文。
资料：[粘贴内容或提供本地文件]
```

首次使用时智能体会简短询问是否更换头像和署名；未要求替换就沿用默认品牌，不必先准备自己的素材。需要定制时提供头像文件、显示名和可选辅助署名即可。模板署名不代表作者审核了使用者生成的内容。

## 能交付什么

- 默认 6 张（通常 5～8 张，用户指定优先）的真实图片：封面、逐页知识点、总结或避坑。
- 分镜、每页提示词及来源记录。
- 一个整套 HTML 预览入口。
- 发布标题、正文、话题与置顶评论。

本项目是给智能体执行的 Skill 和默认素材，不是独立的一键生图软件。实际生图需要所在智能体提供工具或用户自行配置服务，额度与费用由对应服务决定。没有生图能力时只能交付待生图方案，不能冒充已完成成品。不自动登录或发布小红书。

## 设计约定

左上角头像与署名固定保留；画面里的羊讲解员不能代替头像。默认不加页码与期数角标。模型无法保留准确头像或中文时，应使用可用的排版能力补入原图和文字，并检查最终成图。标题常用「具体知识点，一组漫画讲清楚」，不保证流量。

蜡笔漫画风也可以使用原创角色。第三方漫画角色、名称与商标不因本项目开源而获得授权。默认头像作为模板品牌素材单独说明，详见 LICENSE。
